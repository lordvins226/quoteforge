QuoteForge ships eight commands. They compose well: `validate` gates CI, `generate` produces one card, `slides` produces a deck, `batch` produces many, `studio` opens the editor, `preview` watches a file, `themes` manages theme JSON, and `doctor` checks the install.

## `generate`

Render a single card JSON to PNG.

```bash
quoteforge generate <file> [options]
```

### `--fit-content`

The `--fit-content` flag (alias `--trim`) crops the output to the content bounding box plus the theme's padding. Output dimensions become content-dependent instead of fixed to the size preset. This is useful for single cards where you want minimal void space.

```bash
quoteforge generate card.json --fit-content    # crop to content, no surrounding whitespace
```

When used with `slides`, the flag may produce slides with different heights (if content height varies per slide). This is intentional but worth noting in deck workflows. On a deck, `--fit-content` also drops the slide-counter overlay, which sits outside the content box.

### `--safe-aspect`

The `--safe-aspect <ratio>` flag constrains the layout so all content survives a center-crop toward the given ratio. This is useful when rendering cards for embedded display in mismatched `object-fit: cover` containers (e.g., a square card to be embedded in a 16:9 player or carousel).

**Accepted ratio formats:**
- `W:H` (e.g., `16:9`, `4:3`)
- `WxH` (e.g., `16x9`)
- Decimal (e.g., `1.78` for 16:9)

**Recommendation:** pair `--safe-aspect` with `align: center` (the default). Do not combine with `--fit-content` (they have opposite intents: safe-aspect maintains full size, fit-content crops to content).

**Example:** A square card (1080×1080) made safe for a 16:9 embed:

1. Create a card with square dimensions (`size: "instagram-sq"`) and `align: "center"`:

```json
{
  "template": "quote",
  "theme": "dark-teal",
  "size": "instagram-sq",
  "align": "center",
  "blocks": [
    { "type": "headline", "parts": [{ "text": "Center-safe for 16:9", "style": "normal" }] },
    { "type": "text", "content": "All content fits in the central 1920×1080 band, surviving center-crop to 16:9." }
  ]
}
```

2. Render it with `--safe-aspect 16:9`:

```bash
quoteforge generate card.json --safe-aspect 16:9
```

The output remains 1080×1080 but all content is constrained to the central 16:9 region (1080×607px). When embedded in a 16:9 container with `object-fit: cover`, the entire content box will remain visible.

Options:

| Flag | Default | Description |
|------|---------|-------------|
| `-t, --theme <name>` | (from file) | Override theme |
| `-s, --size <name>` | (from file) | Override size (e.g. `instagram-sq`) |
| `-o, --output <path>` | `outputs/` | Output directory |
| `--scale <n>` | `2` | Pixel ratio (1 or 2) |
| `--safe-aspect <ratio>` | — | Constrain content to safe band for center-crop (e.g. `16:9`) |
| `--fit-content` | — | Crop output to content bounding box + theme padding |
| `--no-timestamp` | — | Don't append ISO timestamp to filename |
| `--open` | — | Open the PNG after generation |

## `slides`

Render a deck JSON into numbered PNGs + a ZIP.

```bash
quoteforge slides <file> [options]
```

Options:

| Flag | Default | Description |
|------|---------|-------------|
| `-t, --theme <name>` | — | Override theme for all slides |
| `-s, --size <name>` | — | Override size for all slides |
| `-o, --output <dir>` | `outputs/<deck>/` | Output directory |
| `--slide <n>` | — | Render only slide N (1-indexed), no ZIP |
| `--no-zip` | — | Skip ZIP creation |
| `--no-counter` | — | Disable counter overlay |
| `--safe-aspect <ratio>` | — | Constrain content to safe band for center-crop (e.g. `16:9`) |
| `--fit-content` | — | Crop each slide to content bounding box + theme padding |
| `--concurrency <n>` | `4` | Parallel render workers |
| `--scale <n>` | `2` | Pixel ratio |
| `--open` | — | Open output folder |

## `batch`

Render every JSON file in a directory.

```bash
quoteforge batch <dir> [options]
```

Options include `--theme`, `--size`, `--output`, `--safe-aspect`, `--fit-content`, `--concurrency`, and `--decks` (to also process deck files).

## `validate`

Zod-validate a card, deck, or theme file. Exits non-zero on failure — wire this into CI.

```bash
quoteforge validate content/my-card.json
quoteforge validate --theme themes/custom.json
```

## `preview`

Watch a file and re-render on change. Opens the PNG in your default viewer.

```bash
quoteforge preview content/examples/quote-twain.json
```

## `studio`

Launch the WYSIWYG editor.

```bash
quoteforge studio [file] [--port 4242] [--no-open]
```

## `themes`

Manage theme JSON files.

```bash
quoteforge themes list
quoteforge themes show obsidian
quoteforge themes create my-theme
quoteforge themes duplicate obsidian my-obsidian
quoteforge themes validate themes/my-theme.json
```

## `doctor`

Report install health — bundled assets, user theme directory, resolved Chrome, runtime versions. Exits **1** if Chrome can't be resolved.

```bash
quoteforge doctor
```

## Environment variables

| Variable | Purpose |
|----------|---------|
| `QUOTEFORGE_CHROME` | Absolute path to a Chrome/Chromium/Edge executable. Skips auto-detect. |
| `QUOTEFORGE_INSTALL_DIR` | Used by `install.sh` to pick the install target (default `~/.local/bin`). |
| `QUOTEFORGE_VERSION` | Used by `install.sh` to pin a specific release tag. |
| `XDG_CACHE_HOME` | Overrides `~/.cache` as the base for bundled-asset unpacking and the Chrome cache. |
| `XDG_CONFIG_HOME` | Overrides `~/.config` as the base for user-authored themes. |

## Exit codes

All validation errors exit with code **1**. Render failures exit **2**. File-not-found exits **1**.
