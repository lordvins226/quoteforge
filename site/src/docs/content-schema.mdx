Every card and deck is a JSON document validated by Zod. Files are auto-detected by their `type` field: `"deck"` → carousel, `"card"` (or no `type`) → single card.

## Card shape

```json
{
  "type": "card",
  "template": "manifesto",
  "theme": "terminal-green",
  "size": "instagram-sq",
  "blocks": [
    {
      "id": "h",
      "type": "headline",
      "parts": [
        { "text": "Ship typographic cards ", "style": "normal" },
        { "text": "from JSON.", "style": "accent-italic" }
      ]
    }
  ]
}
```

**Fields:**

| Field | Type | Required | Notes |
|-------|------|----------|-------|
| `type` | `"card"` | optional | Cards are the default: omitting is fine |
| `template` | string | yes | `"manifesto"`, `"quote"`, `"list"`, or `"minimal"` |
| `theme` | string | yes | Name matching a file in `themes/` |
| `size` | SizeName | yes | One of 22 presets (see below) |
| `blocks` | Block[] | yes (≥1) | Ordered list of content blocks |
| `align` | string | optional | `"top"` \| `"center"` \| `"bottom"` \| `"spread"` (default: `"center"`) |
| `eyebrow` | string | optional | Kicker line above the content, max 48 chars. See Template chrome below |
| `meta` | object | optional | `title`, `created`, `tags`: used by the studio |

## Deck shape

```json
{
  "type": "deck",
  "defaults": {
    "template": "quote",
    "theme": "noir-crimson",
    "size": "instagram-sq"
  },
  "slides": [
    { "id": "s1", "blocks": [{ "id": "h", "type": "headline", "parts": [{ "text": "Slide 1", "style": "normal" }] }] },
    { "id": "s2", "theme": "terminal-green", "blocks": [{ "id": "h", "type": "headline", "parts": [{ "text": "Slide 2", "style": "normal" }] }] }
  ]
}
```

Each slide inherits from `defaults`; any field on the slide overrides it. Slides require a unique `id`.

## Template chrome

`eyebrow` is a small kicker line rendered above the main content. It is an optional string of at most 48 characters, and it sits at the same level as `template`: on a card root, on a single slide, or in a deck's `defaults`.

```json
{
  "template": "cover",
  "theme": "paper-cream",
  "size": "og",
  "eyebrow": "Issue 01",
  "blocks": []
}
```

In a deck, a slide's own `eyebrow` wins over the one in `defaults`, and a slide with neither renders none.

Only 8 of the 28 templates have a slot for it: `cover`, `memo`, `receipt`, `split`, `spotlight`, `terminal`, `ticket`, and `window`. Set it on any other template and the field is ignored, but the CLI says so rather than dropping it silently:

```
⚠ Template "manifesto" has no eyebrow slot, so the "eyebrow" field will not render.
```

## Block types

Eleven block types live in `BlockSchema`:

### `headline`: display text
```json
{
  "id": "h",
  "type": "headline",
  "parts": [
    { "text": "Bold statement.", "style": "normal" },
    { "text": " Emphasis here.", "style": "accent-italic" }
  ]
}
```

### `blockquote`: pull quotes with a border
```json
{
  "id": "q",
  "type": "blockquote",
  "parts": [
    { "text": "Short quote.", "style": "bold" }
  ]
}
```

### `text`: paragraph copy
```json
{ "id": "p", "type": "text", "content": "Plain-text paragraph." }
```

### `bullet-list`: labeled rows
```json
{
  "id": "list",
  "type": "bullet-list",
  "items": [
    { "label": "01", "text": "First point" },
    { "label": "02", "text": "Second point" }
  ]
}
```

### `callout`: boxed highlights (same shape as bullet-list)
```json
{
  "id": "call",
  "type": "callout",
  "items": [
    { "label": "Tip", "text": "Keep bullet-list labels under 4 characters for visual balance." }
  ]
}
```

### `divider`: horizontal rule
```json
{ "id": "d", "type": "divider" }
```

### `spacer`: explicit vertical gap
```json
{ "id": "gap", "type": "spacer", "size": "md" }
```

`size` is `"sm" | "md" | "lg"`.

### `image`: inline image
```json
{
  "id": "img",
  "type": "image",
  "src": "./logo.svg",
  "alt": "Company logo",
  "width": "md",
  "align": "center"
}
```

- `src`: a remote URL (`https://...`), a local file path, or a `data:` URI. Local
  paths are resolved relative to the content file's directory and inlined at render
  time (`png`/`jpg`/`jpeg`/`webp`/`gif`/`svg`). For security, the Studio server only
  accepts `http(s):`/`data:` sources, local file paths work via the CLI only.
- `alt`: optional alternative text.
- `width`: `"sm" | "md" | "lg" | "full"` (33% / 50% / 75% / 100% of the content
  column). Defaults to `"full"`.
- `align`: `"left" | "center" | "right"`. Defaults to `"center"`.

In the Studio, add an Image block and either paste a URL or upload a file (the upload
is embedded as a `data:` URI, so the card stays self-contained).

### `stat`: one oversized figure
```json
{ "id": "s", "type": "stat", "value": "28", "unit": "×", "label": "Templates", "note": "in five families" }
```

`value` is a string, so `"1.2M"` and `"99.9"` are both fine. `unit`, `label`, and `note`
are optional. Suits the `stat` template, which scales the figure to the canvas.

### `code`: numbered source lines
```json
{
  "id": "c",
  "type": "code",
  "filename": "render.ts",
  "lang": "ts",
  "lines": ["const card = load(file);", "await render(card, theme);"]
}
```

`lines` is an array of strings, one per rendered line, and is the only required field.
The template numbers the lines. `filename` renders as a tab above the block. `lang` is
accepted by the schema but no built-in template renders it today, so treat it as metadata
for your own tooling. There is no syntax highlighting: the block is monospace text in the
theme's colors.

### `chart`: horizontal bars
```json
{
  "id": "ch",
  "type": "chart",
  "unit": "%",
  "rows": [
    { "label": "Bun", "value": 92 },
    { "label": "Node", "value": 61, "muted": true }
  ]
}
```

Each row needs a `label` and a `value` between 0 and 100, used directly as the bar's
width percentage. `unit` is the suffix shown next to each value and defaults to `%`.
`muted` renders the bar in the body color at 45% opacity instead of the accent. Pure CSS,
no chart library.

## Part styles

`headline` and `blockquote` blocks hold an array of **parts**, each styled independently:

| Style | Effect |
|-------|--------|
| `normal` | Default weight/color |
| `bold` | Bold weight |
| `italic` | Italic (same color) |
| `accent` | Accent color, normal weight |
| `accent-italic` | Accent color, italic |
| `mono` | Monospace (uses body font family) |
| `muted` | 60% opacity |

This is what makes one line of text read with rhythm: a `normal` start, an `accent-italic` punchline.

### Custom dimensions

When no preset fits, use `custom` and supply both dimensions at the root of the card:

```json
{
  "template": "manifesto",
  "theme": "dark-teal",
  "size": "custom",
  "width": 1200,
  "height": 900,
  "blocks": [ ... ]
}
```

`width` and `height` are integers between 1 and 8000, and both are required when
`size` is `"custom"`. Supplying them alongside a preset size is rejected, because the
preset would win and the values would be silently ignored.

The same keys work in a deck's `defaults`, and on an individual slide that sets
`"size": "custom"` explicitly.

### Vertical alignment

Every card controls content placement with the `align` field:

```json
{
  "template": "manifesto",
  "theme": "dark-teal",
  "size": "twitter",
  "align": "center",
  "blocks": [ ... ]
}
```

`align` accepts four values (default: `center`):

| Value | Effect |
|-------|--------|
| `top` | Content aligns to the top of the canvas |
| `center` | Content is vertically centered (default) |
| `bottom` | Content aligns to the bottom |
| `spread` | Content is distributed edge-to-edge (pre-0.5.0 behavior) |

In decks, set `align` in the `defaults` object, or override it on individual slides.

Note: **In v0.5.0, the default changed from `spread` to `center`**. Existing cards will re-render with content grouped in the middle. Add `"align": "spread"` to your card root to restore the previous look.

## Validation

Check any card or deck without rendering it:

```bash
quoteforge validate content/my-card.json
```

Errors point at the exact path (e.g. `blocks[2].parts[0].style`) and the expected type, which makes template drift obvious before you spend a Puppeteer run on it.
